How we published it

GitHub

We created a repository under our group's GitHub organization and uploaded our HTML, CSS and JavaScript files there. GitHub stores our code and keeps a history of every change we make.

Vercel

We connected our GitHub repository to Vercel, a free hosting service. Vercel automatically publishes the site to a live web address, and updates it again each time we upload new files to GitHub.
