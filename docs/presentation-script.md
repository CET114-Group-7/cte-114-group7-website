## 1. Introduction

Good morning/afternoon. We are Group 7 from the Department of Computer Engineering, School of Technology, Kano State Polytechnic. Our course is CTE 114, Internet and Web Technology.

For this assignment, every group was asked to design and build a 4-page website of our own choice. We chose to build a personal portfolio website for our group.

## 2. What our website contains

Our website has four pages:

1. **Home**: introduces our group and gives a quick summary of the site.
2. **Team**: lists all ten members of our group with their names and matric numbers.
3. **Skills**: shows the tools and skills we used to build the site, and the small projects behind it.
4. **Contact**: a message form and our group and department details.

## 3. Tools we used to build it

We built the website using three basic web languages:

- **HTML** for the structure and content of each page.
- **CSS** for the colors, fonts, and layout.
- **JavaScript** for small interactive features, like the mobile menu button and the contact form.

We did not use any framework. Everything was written by hand so that every member of the group could understand the code.

## 4. How we made it live (GitHub and Vercel)

After building the website, we needed a way to publish it on the internet so anyone can view it from a link, not just on our computers. We did this using two free tools:

- **GitHub**: we created a repository (an online storage folder for our code) under our group's GitHub organization, and uploaded our HTML, CSS, and JavaScript files there.
- **Vercel**: we connected our GitHub repository to Vercel, a website hosting service. Vercel automatically builds and publishes our site to a live web address.

Because the two are connected, whenever we upload new or changed files to GitHub, Vercel automatically updates the live website within about a minute. This means we did not need to buy any hosting or pay any money to put our project online.

Our links are:

- Live website: https://cte-114-group7-website.vercel.app
- GitHub repository: https://github.com/CET114-Group-7/cte-114-group7-website
- GitHub organization: https://github.com/CET114-Group-7

## 5. Live demonstration

At this point we will open our live link and walk through each of the four pages: Home, Team, Skills, and Contact.

Suggested things to point out while demonstrating:
- The menu bar stays fixed at the top of the screen as you scroll.
- The site adjusts correctly between a phone screen and a computer screen.
- The mobile menu button opens and closes a dropdown list of pages.
- The Contact page has a working message form.

## 6. Conclusion

This project taught us how to plan, design, and publish a website as a team. It also gave us hands-on experience with tools that real web developers use every day, including GitHub for version control and Vercel for hosting.

Thank you for listening. We are ready to take any questions.
